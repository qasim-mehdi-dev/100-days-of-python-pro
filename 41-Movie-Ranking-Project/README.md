# Day 41: Introduction to Web Development & Semantic HTML Architecture

## 🚀 Overview
Today marks the official transition into frontend web development. I migrated my core workspace environment from PyCharm to Visual Studio Code (VS Code) to leverage specialized live-preview extensions and integrated source control management. 

This module focused on understanding the underlying infrastructure of the World Wide Web and how browsers parse static files to render visual layouts.

## 🧰 Key Concepts Mastered
* **The Web Trifecta**: Conceptualized the decoupled architecture of modern websites:
  * **HTML**: Document object model and structure.
  * **CSS**: Aesthetic design and presentation layers.
  * **JavaScript**: Client-side execution and interactivity profiles.
* **Document Object Trees**: Explored structural markup segmentation.
* **Inspect Element Auditing**: Utilized native browser developer tools to isolate HTML elements, modify live client-side structural nodes, and audit runtime rendering behaviors.

## 🏷️ HTML Semantic Tags Implemented
* `<h1>` - `<h6>`: Hierarchical structural heading layout tags.
* `<p>`: Text content block paragraphs.
* `<hr>`: Horizontal rule thematic breaks for structural segmentation.
* `<br>`: Isolated line breaks for inline text control.
