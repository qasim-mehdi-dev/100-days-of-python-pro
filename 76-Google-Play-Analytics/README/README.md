## Day 76 - Google Play Store Analysis

### Concepts Covered
- .sample() for random row preview
- .duplicated() and .drop_duplicates() for deduplication
- .str.replace() for cleaning messy numeric strings
- pd.to_numeric() for type conversion
- Plotly Express: pie, donut, bar, horizontal bar, scatter, box charts
- .mul() for column multiplication (Revenue = Installs × Price)
- .str.split(expand=True).stack() for splitting multi-value genre column
- Grouped bar charts with barmode='group'
- Log scale axes for skewed data

Full analysis of 10,000+ Google Play Store apps including cleaning, deduplication, category popularity, free vs paid comparison, revenue estimates and price analysis using interactive Plotly charts
