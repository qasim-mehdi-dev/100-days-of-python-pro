# Developer Portfolio Layout

A modern, high-performance web portfolio layout optimized for quick scanning and responsive presentation. Built using the Bootstrap 5 framework, custom visual grids, and refined typography.

## 🚀 Features
* **Postcard Grid System:** A customized multi-column layout featuring tightly cropped project imagery to reduce page scrolling and maintain grid symmetry.
* **Modern Typography:** Integrated with Google Fonts (`DM Sans`) for crisp, professional readability.
* **Immersive Hero Header:** An eye-catching, full-width jumbotron header with a high-contrast typography layer.
* **Responsive Architecture:** Fully adapts across mobile viewports, tablet scales, and desktop screens using Bootstrap's utility engine.

## 🛠️ Built With
* HTML5
* CSS3 (Custom Grid Alignments & Visual Filtering)
* Bootstrap 5 (Core Layout Component Architecture)
* Google Fonts API
