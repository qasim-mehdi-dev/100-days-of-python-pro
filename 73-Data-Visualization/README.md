## Day 73 - Stack Overflow Language Trends

### Concepts Covered
- Matplotlib line charts and figure customization
- pivot() to reshape long data into wide format
- fillna(0) to handle missing language data
- rolling(window=6).mean() for trend smoothing
- Looping through columns to plot all languages

### Project
Visualizes Stack Overflow post counts 2008-2020 per programming language showing popularity trends over time with smoothed rolling averages
