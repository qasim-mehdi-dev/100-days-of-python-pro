# 62 - Cafe & WiFi Website

A Flask web application that allows users to submit and view information about cafes, including coffee quality, WiFi strength, and power socket availability.

## Features

* Submit new cafe entries through a Flask-WTF form
* Form validation using WTForms validators
* URL validation for Google Maps locations
* Store cafe information in a CSV file
* Display all submitted cafes in a table
* Bootstrap styling for a cleaner user interface

## Technologies Used

* Python
* Flask
* Flask-WTF
* WTForms
* Flask-Bootstrap
* CSV
* Jinja Templates

## What I Learned

* Creating advanced forms with Flask-WTF
* Using SelectField dropdown menus
* Form validation with DataRequired and URL validators
* Redirecting users after successful submissions
* Reading and writing CSV files
* Displaying dynamic data with Jinja templates
* Integrating Bootstrap with Flask applications
