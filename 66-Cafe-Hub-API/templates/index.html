Cafe & Wifi API Documentation

Welcome to the Cafe & Wifi API. Use the following endpoints to interact with our database of remote-work-friendly spots.

Available Endpoints

GET /random

Fetch a single random cafe from the database.

Response (200 OK):

{
  "cafe": {
    "id": 1,
    "name": "Cafe Nero",
    ...
  }
}

GET /all

Returns a list of all cafes currently stored in the system.

GET /search

Search for cafes by location name.

URL Parameters: loc (e.g., /search?loc=London)

POST /add

Add a brand new cafe to the database.

Body Data (x-www-form-urlencoded):

  • name (String)
  • map_url (String)
  • img_url (String)
  • location (String)
  • seats (String)
  • has_toilet (Boolean: "True"/"False")
  • has_wifi (Boolean: "True"/"False")
  • has_sockets (Boolean: "True"/"False")
  • can_take_calls (Boolean: "True"/"False")
  • coffee_price (String)

PATCH /update-price/<cafe_id>

Update the coffee price of an existing cafe entry.

URL Parameters: new_price (e.g., /update-price/19?new_price=£3.40)

DELETE /report-closed/<cafe_id>

Remove a cafe entry from the database. Requires a valid security key.

URL Parameters: api-key (e.g., /report-closed/17?api-key=TopSecretAPIKey)
