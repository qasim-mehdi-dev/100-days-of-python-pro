# Day 78: Machine Learning Foundations – Linear Regression Models, Statistical Inference, and Advanced Plot Distributions using Seaborn

## 🚀 Overview
Today's module introduced predictive data modeling workflows using a dataset of over 5,000 films to determine the mathematical relationship between financial production budgets and global box office returns. The project involved designing text-stripping pipelines to sanitize currency metrics, separating the data into chronological era subsets using floor division calculations, rendering styled statistical regression lines using Seaborn, and utilizing Scikit-Learn to build, train, and evaluate a univariate Linear Regression model to run predictive inferences on studio project returns.

## 🧰 Key Concepts Mastered
* **High-Fidelity Regression Plotting**: Leveraged Seaborn's `sns.regplot()` engine to simultaneously overlay raw continuous feature distributions and computed lines of best fit.
* **Scikit-Learn Model Fitting**: Configured a linear regression engine utilizing `regression.fit()` to calculate optimized parameters across multidimensional structural feature matrices.
* **R-Squared Evaluation Metrics ($R^2$)**: Measured the model's goodness-of-fit score, tracking the exact proportion of variance in the target variable explained by budget features.
* **Predictive Asset Forecasting**: Formulated explicit mathematical equations using extracted slope coefficients and intercepts to run automated estimation tests on future production values.
